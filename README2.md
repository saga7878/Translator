# VSCode Translator 🚀

A powerful and elegant VSCode translation extension for effortless code reading and writing.

## ✨ Key Features

- 🌐 Multiple Translation Engines: Microsoft Translate and AI Translation (Github Copilot)
- 🔍 Text Selection Translation
- 💡 Smart Hover Translation with Cache
- 🔄 Bi-directional Translation
- 📋 One-click Text Replacement
- 📝 Translation Panel
- ⚡ Keyboard Shortcuts
- 🔒 Offline Cache Support

## 🔌 Installation

1. Search "Translator" in VS Code marketplace
2. Click install
3. Restart VS Code

## 🛠️ Configuration

### Translation Service Configuration

In VSCode settings, you can choose your preferred translation service:

1. **Microsoft Translate** (Default)
   - No additional setup required
   - Suitable for everyday translation needs
   - Setting value: "microsoft"

2. **GitHub Copilot Translation**
   - Requires GitHub Copilot extension
   - Provides AI-enhanced translation capabilities
   - Setting value: "copilot"

How to configure:

1. Open VSCode Settings (`Ctrl+,` or `Cmd+,`)
2. Search for "translator.service"
3. Select your desired translation service from the dropdown menu

### Basic Settings

- **Minimum Translation Length**: 2 (default)
- **Source Language**: Auto-detect supported
- **Target Language**: Configurable

### Hover Settings

- **Enable/Disable Hover**: Toggle hover translation functionality
- **Hover Delay**: 300ms (default)
- **Cache Duration**: 3600s (default)

## ⌨️ Keyboard Shortcuts

| Windows/Linux | Mac | Function |
|--------------|-----|-----------|
| `Ctrl+Shift+T` | `Cmd+Shift+T` | Hover Translation |
| `Ctrl+Shift+V` | `Cmd+Shift+V` | Open Translation Panel |
| `Ctrl+Shift+R` | `Cmd+Shift+R` | Translate and Replace |
| `Ctrl+Shift+C` | `Cmd+Shift+C` | Copy Translation |
| `Ctrl+Shift+E` | `Cmd+Shift+E` | Replace with Translation |
